# Hello World Python Project

A clean, modular Python Hello World application with unit tests.

## Overview

This repository provides a simple Python module that outputs "Hello, World!" along with automated test coverage using `pytest`.

## Project Structure

```
├── hello.py       # Main application module containing greeting logic
├── test_hello.py  # Unit tests using pytest
├── .gitignore     # Git ignore rules
└── README.md      # Project documentation
```

## How to Run

To run the Hello World program:

```bash
python3 hello.py
```

Output:
```text
Hello, World!
```

## Running Tests

To run the automated tests, ensure `pytest` is installed and run:

```bash
pytest
```
